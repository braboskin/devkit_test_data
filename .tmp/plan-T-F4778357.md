# План T-F4778357 — экраны: Главная, Чат, Вход, Онбординг

## Контекст

- Примитивы после T-4FC8A97B: `Panel`, `PageFrame`, `PageHeader` (eyebrow),
  antd-first (`Button`, поля, `Tag`, `Empty`, `Skeleton`, `Progress`, `Steps`,
  `Collapse`, `Modal`), токены Graphite, `motion`.
- `pages/home/ui/Home.tsx` — виджеты (KPI, «Сегодня», события, входящие,
  развитие, файлы, агент) на классовых стилях `base.css` (`.panel`, `.card`,
  `.badge*`).
- `pages/chat/ui/Chat.tsx` — список чатов, тред, композер, трейс;
  нативный `<select>` выбора агента, `<details class="trace">`.
- `pages/login/ui/Login.tsx`, `app/SetupWizard.tsx` — формы на классах
  (`.panel`, `.field`); `ModelStep` уже переведён на `LlmSettingsForm`
  в T-D24FD0BF — его контракт не менять.
- Тесты: `tests/test_web_build.py` читает литералы в `AppShell.tsx`/`App.tsx`,
  но не в этих экранах; e2e `onboarding.spec.ts` (deep link шага опроса, баннер
  после пропуска).

## Шаги

1. **Главная.** `PageFrame` + `PageHeader` (eyebrow с датой, описание, действия);
   KPI — карточки `Panel` с `tabular-nums`; виджеты на `Panel`; задачи —
   antd `Checkbox` + `Tag` (сфера), время `tabular-nums`; состояния
   `Skeleton`/`EmptyState`/`ErrorNote`; motion на появлении панелей (stagger,
   ≤ 8 элементов).
2. **Чат.** Список чатов — `Panel` со скроллом, активный элемент
   `var(--accent-soft)`; выбор агента — `SelectField` (antd `Select`); тред —
   `m` на появлении сообщений; композер — `styled` с фокус-кольцом акцента,
   `Enter`/`Shift+Enter` сохранить; tool-call карточка — вложенная поверхность
   `var(--sunken)`; трейс `<details>` → antd `Collapse`; статусы —
   `role="status"`/`aria-live`.
3. **Вход.** `Panel` + `TextField` (пароль `type="password"`,
   `autoComplete="current-password"`), ошибка — `Alert`/`ErrorNote` под полем,
   submit-блокировка `Button loading`.
4. **Онбординг.** `PageFrame`; прогресс шагов — antd `Steps` (compact,
   текущий/пройденные), поля — обёртки, `SelectField` вместо нативных
   `<select>`; превью «Создадим» — `Panel`; кнопки «Назад/Пропустить/Утвердить»
   — `Button`; `ModelStep` оставить как есть (импорт `LlmSettingsForm`).
5. **Проверки.** `tsc/eslint/steiger/prettier/build`; e2e `onboarding.spec.ts`
   зелёный; axe на `/`, `/chat` (маршрут добавить в `a11y.spec.ts` только если
   он уже там — иначе e2e).

## Acceptance

- A3 (часть): Главная, Чат, Вход, Онбординг — на примитивах и токенах, в
  тёмной и светлой теме читаемы, без белых островов и обрезанных подписей.
- A5: появление панелей/сообщений и stagger списков через `motion`, при
  `effects=off`/`prefers-reduced-motion` — без анимации.
- A11 (часть): в этих экранах нет нативных `<select>/<input>/<textarea>` —
  только обёртки; antd `Steps`/`Collapse` использованы.
- e2e (`onboarding.spec.ts`) и axe зелёные; поведение deep link шагов не
  изменилось.

## Риски

1. **SetupWizard большой (~1000 строк)** — правка шагов по одному, без
   переписывания логики localStorage/deep link.
2. **Чат: композер и Enter** — поведение клавиш и отправка не должны
   измениться; покрыть ручной проверкой + существующим e2e, если есть.
3. **Stagger-анимации** могут увеличить время до интерактивности — не больше
   8 элементов и 260 мс.
4. **Тесты с литералами** вне scope, но падение `test_web_build` возможно при
   удалении строк из `SetupWizard` — тексты шагов сохраняем.
