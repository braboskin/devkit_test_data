# T-DB0D3FD0 — Онбординг: маршруты /setup/*, deep links, баннер, идемпотентность

## Что сделано

- **URL-шаги**: `/setup` (приветствие), `/setup/model`, `/setup/disk`,
  `/survey?step=N` (9 шагов опроса, индексы 0–7). Шаг из URL приоритетнее
  localStorage; при переходах адрес обновляется `history.replaceState`, поэтому
  reload возвращает на тот же шаг, а ссылку можно сохранить/переслать.
- Важная деталь: `createBrowserRouter` при старте нормализует URL раньше, чем
  монтируется визард, поэтому исходный адрес запоминается на уровне модуля
  (`INITIAL_URL`) — без этого deep link терялся и открывался первый шаг.
- **Баннер**: «Пропустить опрос» ставит в профиль `onboarding_done=true` и
  `onboarding_skipped=true`; на Главной появляется баннер «Опрос не завершён» с
  кнопкой «Продолжить опрос» → `/survey?step=0`.
- **Идемпотентность**: перед созданием целей/привычек/метрик шаг сверяется с
  серверными списками (`/api/goals`, `/api/habits`, `/api/metrics`) и не создаёт
  дубликаты; сферы уже дедуплицировались по имени. Повторный проход после сброса
  localStorage безопасен.
- **E2E**: два новых сценария — deep link `/survey?step=2` открывает шаг «Цели»;
  баннер после пропуска ведёт на `/survey?step=0`. Всего e2e теперь 10.
- Тестовая инфраструктура: `installMocks(page, profileData)` параметризован
  профилем; в `vite.config.ts` отключён preview-прокси `/api` (иначе непойманный
  мок уходил на живой бэкенд и 401 разлогинивал приложение через
  `atlas:unauthorized`). Dev-прокси не тронут.

## Риски

- **`/login` отдельным маршрутом не сделан**: как и раньше, форма входа
  показывается гейтом `App` при отсутствии сессии; deep link `/login` откроет
  её же через гейт, но URL остаётся `/login` только если он был в адресе.
- **Идемпотентность через сверку с сервером**, а не через ключи
  `onboarding_created` в профиле (как в плане): поведение то же (дублей нет),
  меньше лишних записей в JSON; серверное поле не понадобилось.
- **localStorage** остаётся резервом прогресса: источник правды — URL, но
  «созданное в этом проходе» хранится локально.
- Preview больше не проксирует `/api` — для ручного просмотра собранного dist с
  живым бэкендом используйте dev-сервер (`npm run dev`) или стенд на :8000.
