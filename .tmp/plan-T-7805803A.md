# План T-7805803A — экраны: Календарь, Задачи, Файлы

## Контекст

- Календарь — `FullCalendar 6.1.22` (`shared/ui/calendar.tsx`) + свои
  `calendar.css` (87 строк) и классы `base.css` (`.calendar-*`, `.view-switch`,
  `.chip`).
- Задачи — дерево/доска (SVAR Kanban)/гант (SVAR Gantt): классы `.ui-board`,
  `.ui-gantt` (e2e `shell.spec.ts` ищет `.ui-gantt`), 8 нативных `<select>`,
  5 `<input>`, 5 нативных `<button>` в `pages/tasks/ui/Tasks.tsx`.
- Файлы — `pages/files/ui/Files.tsx` с серверной пагинацией (LIMIT 100,
  кнопка «Дальше»), `files.css` (17 строк), фильтры `SelectField`.
- Вендорные переопределения — `shared/ui/vendor.ts` (создан в W1).
- antd-first: виды календаря — `Segmented`, пагинация — `Pagination`,
  даты — `DateField withTime`, мультиселект `blocked_by` — `SelectField
  mode="multiple"`.

## Шаги

1. **Календарь.** Тулбар: `PageFrame`/`PageHeader`, вид (`Год/Месяц/Неделя/
   День/Agenda`) — antd `Segmented` вместо `<select>`; навигация
   `prev/next/Сегодня` — `Button`; панель календаря — `Panel`; тема
   FullCalendar — через `vendor.ts` (`--fc-border-color`, `--fc-today-bg-color`,
   `--fc-page-bg-color`, `--fc-neutral-bg-color` = токены), скин в `styled`
   обёртке `shared/ui/calendar.tsx`; удалить `pages/calendar/ui/calendar.css`.
2. **Задачи.** Все нативные контролы → обёртки (`TextField`, `SelectField`,
   `DateField withTime`, `SelectField mode="multiple"`, `Button`); панели —
   `Panel`; статусы — `Tag`; дерево — `TreeList` (antd `Tree`); представления
   переключаются существующим способом, `.ui-board`/`.ui-gantt` сохранить на
   обёртках `shared/ui/board.tsx`/`gantt.tsx` (размеры — из `vendor.ts`).
3. **Файлы.** Фильтры — `SelectField`; статусы — `Tag` (`DocBadge`); таблица —
   `Table` (antd); пагинация — antd `Pagination` при известном `total`
   (если API не отдаёт `total` — оставить «Дальше», зафиксировать в отчёте);
   удалить `pages/files/ui/files.css`.
4. **Проверки.** `tsc/eslint/steiger/prettier/build`; e2e `shell.spec.ts`
   (`.ui-gantt`, ленивые чанки) и `a11y.spec.ts` (`/calendar` с исключением
   `.fc`); ручная сверка тёмной/светлой темы календаря и доски.

## Acceptance

- A3 (часть): Календарь, Задачи, Файлы на примитивах и токенах, читаемы в
  обеих темах; на теле таблиц и списков нет стекла.
- A11 (часть): нет нативных `<select>/<input>/<textarea>/<button>` в этих
  экранах; antd `Segmented`/`Pagination` использованы; `.ui-gantt`,
  `.ui-board` сохранены.
- `calendar.css` и `files.css` удалены; e2e и axe зелёные; пагинация не
  ломает серверный `offset`.

## Риски

1. **FullCalendar-скин** — их CSS не на Emotion; переопределяем только
   переменные и обёртку, не внутренности (риск хрупких селекторов).
2. **SVAR**: `.ui-gantt`/`.ui-board` нужны e2e; высоты после переноса из
   `ui.css` проверить визуально.
3. **Пагинация**: без `total` antd `Pagination` не покажет страницы —
   оставляем «Дальше», это осознанное решение, а не недоделка.
4. **Календарь на мобильном** (ширина < 700) — текущие media-правила в
   `base.css`; после перевода экрана проверить снап-скролл.
