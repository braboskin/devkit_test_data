# План S4: качество — E2E, axe, ленивая загрузка, снос старого

## Контекст

- Все ключевые задачи в `main`: каркас, бэкенд, экраны S2, дизайн-система,
  проект (доска/гант). Бандл вырос до 582 kB gzip (SVAR + FullCalendar).
- В `pages` остались неиспользуемые роутером старые экраны: `today`
  (заменён Главной) и `documents` (заменён Файлами). На них ссылаются тесты.
- Нет E2E и a11y-проверок; профиль проверок не содержит e2e.
- ТЗ §10 (A11, A12): Playwright + axe на критические пути, снос старых экранов,
  редиректы.

## Шаги

1. **Playwright**: devDependencies `@playwright/test`, `@axe-core/playwright`;
   `viewer/e2e/` с конфигом. Тесты идут против `vite preview` собранного
   `dist` с **замоканными `/api/**`** (`page.route`), чтобы не поднимать
   бэкенд/БД в CI; сценарии:
   - логин (мок) → Главная;
   - сферы: создание (PATCH/POST замоканы) → карточка;
   - проект: переключение Список/Доска/Гант, доска рендерит карточки;
   - календарь: открыть модалку события, сохранить;
   - файлы: дерево по сферам, карточка файла;
   - тема: переключение светлая/тёмная сохраняется после перезагрузки.
2. **axe**: прогон на Главной, Сферах, Проекте, Календаре, Профиле; падение при
   `serious`/`critical`; список исключений — только с комментарием и причиной.
3. **Профиль и CI**: добавить проверки `e2e` и `a11y` (имена в `devkit.yaml`),
   джобу в `.github/workflows/ci.yml`; существующие проверки не ослаблять.
4. **Ленивая загрузка**: `React.lazy` для маршрутов `/projects/:id` (SVAR) и
   `/calendar` (FullCalendar), Suspense + наш `Spinner`; проверить, что
   начальный чанк уменьшился, а SVAR/FullCalendar ушли в отдельные чанки.
5. **Снос старого**: удалить `pages/today` и `pages/documents`; редиректы
   `/today`→`/`, `/documents`→`/files`, `/documents/:id`→`/files/:id`,
   `/interests`→`/spheres`. Перед удалением перенести нужное:
   автоматическое обновление статусов файлов (`setInterval`/`POLL_MS`) — в
   `pages/files`; тесты `test_web_build`/`test_viewer_acceptance` обновить на
   новые файлы без ослабления утверждений.
6. Проверить, что тяжёлые списки не используют antd Table, AG Grid не втянут,
   `grep` на мёртвые импорты; прогнать Steiger, Prettier, все проверки профиля.
7. Отчёт с реальными цифрами чанков, результатами e2e/axe и списком
   оставшихся старых экранов (chat/settings/jobs/agents) — они уходят в S2e/S5.

## Acceptance

- `npx playwright test` зелёный локально; в CI джоба e2e зелёная.
- axe: нет `serious`/`critical` на пяти экранах (или исключения с причиной).
- `/projects/:id` и `/calendar` грузятся отдельными чанками; начальный бандл
  меньше, чем до задачи (фиксируем «до/после»).
- `pages/today` и `pages/documents` удалены; редиректы работают; тесты
  обновлены без ослабления проверок.
- Проверки профиля зелёные, ноль подавлений.

## Проверки

`web-build`, `typecheck-web`, `lint-web`, `arch-web`, `format-web`, `e2e`,
`a11y`, `unit-tests` — с exit code в отчёт. Новые проверки добавляются в
профиль и CI, не заменяя старые.

## Scope

`viewer/e2e`, `viewer/playwright.config.ts`, `viewer/package.json`,
`viewer/src/app/router.tsx`, `viewer/src/pages/{today,documents,files}`,
`.github/workflows`, `devkit.yaml`, тесты `tests/test_web_build.py`,
`tests/test_viewer_acceptance.py`.

## Риски

- **Моки API** могут разойтись с реальным контрактом: фиксируем формы ответов по
  типам `shared/api`, ревью диффа моков.
- **Playwright в CI** (self-hosted Windows): нужен `npx playwright install`
  chromium; если runner не тянет — шаг установки в CI с кэшем, при
  недоступности — эскалация владельцу, а не тихий skip.
- **axe-ложные срабатывания** на antd/FullCalendar/SVAR: исключения только
  точечные, с причиной; глобально правило не отключаем.
- **lazy + роутер**: Suspense-заглушка не должна ломать URL и прямые ссылки;
  проверить e2e-сценарием.
- **Удаление страниц** ломает тесты, которые читают исходники: обновление
  тестов — часть задачи, ослаблять утверждения нельзя.
