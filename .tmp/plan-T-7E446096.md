## Шаги

1. **Настройки.** `PageFrame` + секции `Panel`: Оформление — `ThemePanel`
   (тема, 8 пресетов акцента, эффекты, фон; дефолт `#334155`); Профиль-JSON —
   `TextAreaField` моноширинный с валидацией; Уведомления — `SwitchField` +
   тихие часы (`TimePicker` через новую обёртку `TimeField` в `shared/ui` —
   согласовать с lead, т.к. это файл W1); Яндекс.Диск — `Panel` + `Button`;
   push — `SwitchField`; `<details class="token-fallback">` → `Collapse`.
2. **Агенты.** Список — `Panel`/`Table`, модель/инструменты — `Tag`,
   формы — обёртки, промпт — `TextAreaField`.
3. **Уведомления.** Список — `Panel` строки с `Badge`-непрочитанным,
   фильтр — `SelectField`, действие «прочитать» — `Button`.
4. **Задания.** `Table` (antd): тип, статус `Tag`, прогресс (`Progress`),
   время, повтор; пусто/загрузка/ошибка — стандартные состояния.
5. **Поиск и Space.** Результаты по группам — `Panel` + `Tag`-счётчики,
   подсветка совпадений — `mark`; `SearchOverlay` — тот же компонент
   результатов, `aria-live`.
6. **Удаление legacy.** Когда все экраны переведены: `styles.css` = только
   `@import './styles/tokens.css'`; удалить `styles/base.css`; убедиться, что
   `rg '\.(panel|field|badge|card|chip|inline-form|cards-grid)' viewer/src` не
   находит классовых стилей в разметке (кроме допустимых `ui-*` и сторонних).
7. **Проверки.** Полный профиль + e2e + a11y; `npm run build` и сравнение
   размера `dist` (шрифт + Emotion + motion).
