# Отчёт T-F4778357 — экраны: Главная, Чат, Вход, Онбординг

## Что сделано

Четыре экрана переведены с legacy-классов на примитивы Graphite; попутно
закрыты два пропуска, которые владелец заметил на ревью: в чате появился
постоянный вход в настройки агентов и подложки панелей.

**Главная.** `PageFrame` + `PageHeader` (eyebrow с датой, описание, действия),
4 KPI-панели с `tabular-nums`, шесть виджетов на `Panel` (Сегодня, Ближайшие
события, Входящие, Развитие, Файлы, Уведомления), баннер незавершённого опроса,
состояния `Skeleton`/`EmptyState`/`ErrorNote`/`Note`, появление панелей через
`m` с stagger 30 мс (две группы ≤ 8). Задачи — antd `Checkbox` + `Tag` сферы;
появление списка сфер — отдельный `GET /api/spheres` (при недоступности теги
не показываются, остальное работает).

**Чат.** Две `Panel` (список диалогов и тред) вместо колонок на голом фоне;
`PageHeader`; шапка треда: название, «агент · модель», **постоянная шестерёнка**
`IconButton` + `Tooltip` (`aria-label="Настройки агентов"`) → `onGoSettings`
(`/settings/agents`); разделитель; активный диалог — `--accent-soft` + граница +
`inset 2px`; `SelectField` вместо нативного `<select>`; тред — пузыри агента
`--raised`, пользователя `--accent-soft` с выравниванием и подписью (различие не
только цветом); трейс сабагентов — antd `Collapse` через новую обёртку
`shared/ui`; композер на `--sunken` с фокус-кольцом, поведение `Enter`/
`Shift+Enter` не тронуто; `role="status" aria-live` для «Агент отвечает…»;
появление сообщений `m` (stagger ≤ 8, 180 мс). Раскладка: панели занимают высоту
экрана (`calc(100vh - 210px)`, минимум 420), списки со своим скроллом, композер
прижат к низу; на <960px — `height: auto`.

**Вход.** Стеклянная `Panel` по центру, `TextField` с настоящими `label`+
`htmlFor`, пароль `autoComplete="current-password"`, `autoFocus` на логине,
ошибка `role="alert"`, кнопка в состоянии `loading`. Логика `onLogin` не менялась.

**Онбординг.** `PageFrame` + собственный холст-градиент (рендерится вне
`AppShell`), прогресс — antd `Steps` вместо строки «Шаг N из M», шаги на
`Panel`, превью в `--sunken` (второго стекла нет), нативные чекбоксы →
`CheckboxField`, поля → обёртки. Deep link (`/setup/*`, `/survey?step=N`),
`localStorage` и идемпотентность не тронуты, `ModelStep` не переписан.

**Публичный API.** В `shared/ui` добавлены обёртки `Tooltip` и `Collapse`, чтобы
страницы не импортировали antd напрямую.

**Дефекты, найденные по пути:**
1. **Кодировка.** `pages/chat/ui/Chat.tsx`, `shared/ui/board.tsx`,
   `shared/ui/gantt.tsx` оказались в двойной кодировке (UTF-8 → cp1251): в
   канбане пострадали видимые подписи колонок («К выполнению / В работе /
   Готово / Отменено»), в чате — почти все строки. Причина в интеграции: одна из
   правок `Chat.tsx` шла через PowerShell, который прочитал UTF-8 как ANSI.
   Исправлено перезаписью файлов штатными файловыми инструментами; сканер
   `.tmp/scan-encoding.py` (UTF-8, без PowerShell) — `files with damage: 0`.
2. **Legacy `base.css` `button[type='button']`** перебивал Emotion-стили
   списков чата — поднято `&&` (как в `Button` и `AppShell`).
3. **emotion форвардил `$own` в DOM** — заменено на `data-own`.
4. **Поля без доступного имени** в онбординге (`TextField`/`SelectField` без
   `id`) — добавлены `id`, axe перестал ругаться на label.

## Риски

1. **Скриншоты на моках**, а не на реальных данных; реальные API-формы
   (`citations`, `status`) в моках пришлось дополнять — при первом запуске на
   живом бэкенде стоит глянуть чат глазами.
2. **Legacy `base.css`** продолжает влиять на нативные `<button>` в ещё не
   переведённых экранах; в чате/главной обойдено `&&`, окончательно уйдёт в
   T-7E446096.
3. **`PATCH` с Главной** — новое действие, которое может конфликтовать с
   офлайн-режимом (в офлайне запрос упадёт, ошибка покажется).
4. **Высота чата** завязана на `100vh - 210px`; при другом размере шапки/паддинга
   стоит перепроверить мобильный и широкий экран.
5. **Кодировка** — процессный риск, а не кодовый: правки текстовых файлов через
   PowerShell запрещены, проверка `.tmp/scan-encoding.py` перед сдачей.
