# Отчёт T-12FFB688 — догон UI по макетам Graphite

## Что сделано

Четыре направления второго прохода закрыты; на экраны вернулось то, что было в
макетах, но не в реализации, а геометрия форм перестала «плавать».

**Главная.** Приветствие по времени суток и имени (`profile.data.name`, иначе
`username`), eyebrow с датой, сводка дня из реальных чисел. Действия «Задача»
(быстрая форма прямо на странице: `TextField`, `DateField`, `SelectField` →
`POST /api/tasks`, тост, перезагрузка) и «Спросить Atlas» → `/chat` с промптом
в `location.state`; чат читает state, заполняет поле и очищает state (без цикла
через `setState` в эффекте). KPI (4) со спарклайнами на реальных рядах; виджеты
«Фокус дня», «Ближайшие события» (по решению владельца возвращён), «Ритм»
(матрица привычек), «Последние документы», «Сферы» с прогрессом, «Агент
заметил». Никаких выдуманных чисел: нет данных — нет ряда/виджета. Сетка 4→2→1,
на 390 px overflow = 0.

**Профиль в настройках.** Блок «Профиль»: фото (`POST /api/profile/avatar`),
логин read-only из `/api/me`, смена пароля — модалка + новый
`POST /api/auth/password` (bcrypt, проверка старого, ≥ 8 символов, 204); поля
«Имя, возраст, город, род деятельности» — типизированная форма поверх
`profile.data` с серверной валидацией (`ProfileIn`, возраст 14–120, строки
≤ 120, пустые удаляются, произвольный JSON сохраняется); JSON-редактор — в
`Collapse` «Дополнительно». Флага «передавать контекст агенту» в коде не было —
подтверждено поиском; добавлен тест, что сведения о владельце попадают в
system-сообщение **всегда**.

**Композер чата (под DeepSeek Chat).** «Новый чат» — primary на всю ширину с
«+»; панель списка с фиксированной шапкой и скроллом только списка; композер —
карточка с фокус-рамкой: скрепка открывает файловый диалог (PDF/DOCX/TXT/MD,
до 3 файлов, ≤ 20 МБ, загрузка через существующий `POST /api/documents`,
чипы с удалением, состояние загрузки), пилюля «Глубокий анализ» с иконкой
(`aria-pressed`), подсказка «Enter — отправить» и круглая кнопка со стрелкой
вверх; во время стрима — круглая «Стоп». Чип `@документы` и панель документов
приложения убраны (решение владельца: агент сам берёт документы).

**Геометрия контролов.** Токены `--control-h: 34px`, `--section-gap: 16px`;
все поля/селекты/пикеры/кнопки — 34 px, селект не меняет высоту при
открытии/выборе (single и multiple, antd 6 `.ant-select-content`), единый ритм
`подпись 12 → контрол → hint 11.5`, `Panel` с padding 16, новый публичный
`FormRow` (`align: end | center`).

**Интеграционные исправления (лид):**
- «Спросить Atlas»: чтение `location.state.prompt` в чате;
- Главная научена не падать на не-массивах (`asList`), из-за чего ломался баннер
  онбординга и e2e;
- e2e-сценарий вложений переведён на файловый диалог (`setInputFiles` + мок
  `POST /api/documents`);
- в матрицу изоляции добавлен `POST /api/auth/password`;
- виджет «Ближайшие события» возвращён на Главную по просьбе владельца.

## Риски

1. **Матрица «Ритм» неполная**: `GET /api/habits` отдаёт только `today` и
   `last_log` — неизвестные дни помечены «нет данных». История отметок хранится
   в `habit_logs`, вынесена в отдельную задачу **`T-D9605E95`** (план v1 draft:
   `dates` в `HabitOut` + заполнение матрицы).
2. **«Фокус за неделю» заменён на «События на неделе»** — в API нет фокус-сессий.
3. **Чип проекта в композере скрыт**: у `Chat` в контракте нет `project_id`.
4. **Смена пароля не инвалидирует другие сессии** (план не требовал).
5. **Выбор модели и `meta` истории** — отдельная задача `T-0D6BFC5A` (план v1
   draft): без неё метка «Глубокий анализ» видна только у стримящегося ответа.
6. **`FormRow` пока не применён на страницах**: список из отчёта WS-U
   (`Home:214`, `Tasks:85/92`, `Files:50/57`, `Growth:116`, `People:49/55`,
   `Settings:106`, `Agents:173`, `Chat:146/166`); в `Search.tsx` локальный
   `FormRow` конфликтует по имени с публичным — перевести при следующей правке.
7. **Загрузка файла не проверена на живом API** (в e2e мок `POST /api/documents`);
   клиентский лимит 3 файла/20 МБ, серверные ограничения остаются главными.
8. **`Panel` padding 16** изменил отступы у 38 «сырых» панелей; проверено
   скриншотами шести рисковых экранов, но мелкие расхождения возможны.
