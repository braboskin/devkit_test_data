# Брифы WS для T-12FFB688 — догон UI по макетам Graphite

Макеты v2 (тёмная тема, 1440×960) — единственный визуальный источник истины:

- `.tmp/design/out/mock-v2-home-dark.png`
- `.tmp/design/out/mock-v2-settings-dark.png`
- `.tmp/design/out/mock-v2-chat-dark.png`
- `.tmp/design/out/mock-v2-fields-dark.png`
- исходник: `.tmp/design/mockup-v2.html` (одна страница, `#home|#settings|#chat|#fields`)

Общие правила для всех WS:

- Только `@emotion/styled` + `var(--*)` из `web/src/app/styles/tokens.css`; страницы
  не импортируют antd напрямую — только через `shared/ui`.
- `shared/ui` меняет **только WS-4**, остальные WS присылают заявку на обёртку
  лиду (как в прошлых волнах).
- Никаких выдуманных данных: нет данных у API — виджет/показатель скрывается.
- `window.alert/confirm` → `useToast`/`useConfirm`; `console`, `any`, подавления
  запрещены.
- Без git и `devkit`; `npm run build`, e2e и a11y запускает лид.
- Проверки перед ответом (из `repo/atlas/web`): `npx tsc --noEmit`,
  `npx eslint .`, `npx steiger ./src`, `npx prettier --check .` — с exit code.

## WS-1. Главная (`web/src/pages/home/**`)

**Цель:** главная из `mock-v2-home-dark.png`.

1. Шапка: eyebrow с датой (уже есть), заголовок — приветствие по времени суток и
   имени: `Доброе утро, {имя}`. Имя из `/api/me` (`username`), если в
   `profile.data.name` есть — оттуда; сводка дня — из реальных чисел (задачи в
   фокусе, привычка под угрозой, свободное время до ближайшего события).
2. Действия: «Задача» (быстрая форма новой задачи прямо на Главной, та же
   логика, что `/tasks`: `TextField`, `DateField withTime`, `SelectField`,
   `Button`) и «Спросить Atlas» (переход `/chat` с предзаполненным промптом —
   через `navigate('/chat', { state: ... })`, чат читает state).
3. KPI (4): цифра + подпись + спарклайн за 7 дней. Данные: задачи (по
   `created_at/status`), привычки (`/api/growth`), документы (`/api/documents`),
   фокус (события/задачи). Нет ряда — спарклайн не рисуется, только цифра.
4. Виджеты в сетке как в макете: «Фокус дня» (уже есть, привести к макету:
   чекбокс, тег сферы, время, badge «N в работе»), «Ритм» (матрица привычек:
   `GET /api/growth/habits` — дни недели, сегодня обведено), «Последние
   документы» (`GET /api/documents?limit=5` — статус `DocBadge`),
   «Сферы» с прогрессом (`GET /api/spheres` + прогресс одним запросом, без N+1;
   нет данных — бар без процента), «Агент заметил» (`/api/notifications` и
   `/api/agent/proposals`; пусто — виджета нет).
5. Светлая тема и мобильная ширина: сетка KPI 4→2→1, две колонки → одна.

   `Avatar`, «Удалить» — если бэкенд поддерживает удаление, иначе скрыть.
2. Логин: read-only из `GET /api/me`.
3. Смена пароля: модалка `Modal` + `PasswordField`? (нет обёртки — заказать в
   WS-4 как `TextField type="password"`), эндпоинт `POST /api/auth/password`
   (`{old_password, new_password}`), bcrypt-проверка старого, ответ 204;
   тесты в `tests/test_app_auth.py` (неверный старый, короткий новый, успех).
4. Поля: имя, возраст, город, род деятельности — типизированная форма поверх
   `profile.data` (`PUT /api/profile`), валидация на клиенте (возраст 14–120,
   строки ≤ 120), бэкенд не меняет схему (JSON). Тест:
   `tests/test_profile_fields.py` — сохранение/чтение и совместимость с
   произвольным JSON.
5. JSON-редактор → `Collapse` «Дополнительно».
6. Убрать чекбокс «передавать контекст агенту» из модели/формы контекста

7. Порядок секций как в макете: левая колонка — Профиль, Модель, Яндекс.Диск;

## WS-4. Контролы и сетка секций (`web/src/shared/ui/**`)

**Цель:** `mock-v2-fields-dark.png` — спецификация.

1. Единая высота контролов **34px** для `TextField`, `TextAreaField` (min-height),
   `SelectField` (включая `.ant-select-content`/`.ant-select-input` в antd 6),
   `DateField`/`TimeField` (`PickerWrap`), `Button`. Никаких `32px` вразнобой.
2. При выборе значения в селекте строка не должна менять высоту: зафиксировать
   `min-height` контента и вертикальное центрирование (`align-items:center`,
   `line-height`), проверить на закрытом/открытом/выбранном состоянии.
3. `FieldRoot`: подпись 12px/1.2, gap 6, контрол, подсказка 11.5px; ошибка —
   `role="alert"`; одинаковый ритм на всех полях.
4. Строки форм: `Row` для разнотипных контролов — `align-items: end`, для
   чекбоксов/переключателей — `center`; зафиксировать компонентом/правилом.
5. Секции: `Panel` padding 16, заголовок с `margin-bottom: 6`, между секциями 16;
   убрать локальные `padding/gap`-хакеры из страниц (согласовать со WS-1..3).
6. Регресс: `npx steiger`, полный e2e/a11y — за лидом; при правке разметки
   предупредить, какие селекторы e2e могли пострадать.
