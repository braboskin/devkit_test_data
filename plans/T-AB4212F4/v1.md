# План S2a: Главная, Развитие, Профиль, Интересы, Проекты, Люди

## Контекст

- Каркас S0 и бэкенд S1 в `main`: роутер, AppShell, темы, `TreeList`,
  `WidgetHost`, summary интереса/проекта, медиа, `search?scope=all`.
- Сейчас маршруты показывают старые экраны: `/` → Today, `/interests` →
  SpheresProjects, `/projects` → редирект, `/people` — старый People,
  `/profile` — заглушка, `/growth` — старый Growth.
- ТЗ §6.1, 6.4–6.6, 6.9–6.10, 6.13, 6.19; Acceptance A5, A8, A10.
- Бэкенд не меняется: используются существующие `/api/*` и новые поля
  (`color/icon/description`, `photo_ref`, `avatar_ref`, summary, медиа).

## Шаги

1. `pages/home`: заменить Today. Приветствие + дата, виджеты «Сегодня»
   (`/api/tasks?status=todo`), «События» (`/api/events`), «Входящие» (задачи без
   `sphere_id`/`project_id`), «Развитие» (цели/привычки/метрики), «Файлы»,
   «Агент» (последние прогоны), быстрые действия. Пустые состояния и скелетоны.
2. `pages/growth`: обернуть существующий Growth в `PageHeader` + табы
   (Цели/Привычки/Метрики/Дневник/Обзоры), не переписывая логику API.
3. `pages/profile`: фото через `uploadAvatar`/`avatarSrc`, имя, контекст
   (возраст/город/профессия) в `UserProfile.data.context` с тумблером
   «передавать агенту», часовой пояс, `ThemePanel`, ссылки.
4. `pages/interests`: сетка карточек по `/api/spheres` + `summary` каждого;
   цвет/иконка, счётчики, прогресс; создание и редактирование
   (color/icon/description); пустое состояние.
5. `pages/interests/:id`: шапка с цветом, дашборд виджетов из `summary`,
   проекты интереса, задачи без проекта этой сферы, люди, файлы.
6. `pages/projects`: список/таблица из `/api/projects` (имя, интерес, дашборд
   прогресса через `summary` или задачи), фильтры, ссылка на проект (деталь —
   задача T-366AA68F).
7. `pages/people`: карточки с фото (`personPhotoSrc`), поиск; `pages/people/:id`
   — карточка человека, связи, задачи, файлы, загрузка фото через
   `uploadPersonPhoto`.
8. Переключить `app/router.tsx` на новые слайсы; старые файлы не удалять
   (снос — T-607A3128).
9. Проверки и отчёт.

## Acceptance

- Главная собирает данные из API и не падает без данных: пусто = CTA.
- Развитие открывается, табы работают, сеть не изменилась.
- Профиль: аватар загружается/отображается, имя и контекст сохраняются,
  тумблер «передавать агенту» сохраняется в `data.context.agent`.
- Интересы: создание с цветом, карточка с summary, страница интереса с
  проектами/задачами/людьми.
- Проекты и люди: списки и карточки людей с фото; deep links работают.
- Мобильная раскладка: карточки в одну колонку, меню Shell не ломается.
