# План T-E12FC73C — Календарь: показать события и кнопку добавления

## Контекст

Владелец: «ни на одной странице календаря не показываются события».
Проверено в этой сессии: **в БД 7 событий есть** (`events`, владелец
совпадает), значит проблема на фронте. Подозрения: формирование
диапазона `from/to` для `/api/events`, маппинг `Event` → `EventInput`
(`start`/`end`/`allDay`), либо передача `events` в `CalendarGrid` для
видов `dayGridMonth/timeGridWeek/timeGridDay/multiMonthYear`.

## Шаги

1. Воспроизвести на живом стенде (`/calendar`) с сессией: посмотреть
   запрос `/api/events?...` и ответ, затем `fcEvents` в React DevTools.
2. Починить маппинг/диапазон; добавить e2e-регресс с мокнутым ответом
   `/api/events` — событие видно в месяце и неделе.
3. Кнопка «Добавить событие» рядом с «Сегодня» (primary, открывает
   существующий диалог создания с текущей датой).
4. Проверить повторяющиеся события (`expand=true`) и часовые пояса
   (отображение в локальной зоне).

## Acceptance

- события видны в месяце, неделе, дне и агенде; e2e-регресс падает, если
  события пропали;
- кнопка добавления рядом с «Сегодня» открывает диалог с выбранной датой;
- светлая/тёмная темы, axe 0.

## Scope

- `web/src/pages/calendar/**`, `web/src/shared/ui/calendar.tsx`,
- `web/src/shared/ui/vendor.ts` (только FullCalendar),
- `web/e2e/**`.

Бэкенд — только если корень окажется в `/api/events` (тогда
`app/backend/features/events/**` + тесты).

## Проверки

Профиль проекта (все обязательные): `web-build`, `typecheck-web`, `lint-web`,
`arch-web`, `e2e`, `a11y`, `unit-tests`, `lint-python`, `typecheck-python`,
`arch-python`. **Профиль и CI теперь совпадают**: `lint-python` включает
`ruff format --check` (коммит `d7e5b99`), расхождение устранено.

## Риски

1. Баг может быть в диапазоне дат и «плавать» по часовому поясу — фиксируем
   тестом с UTC-событием.
2. Мок-события в e2e должны повторять реальный формат `EventOut`, иначе
   регресс бесполезен.
3. Кнопка добавления не должна дублировать существующие действия в
   заголовке.
