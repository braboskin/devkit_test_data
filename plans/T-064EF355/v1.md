# План: Гант — bulk-эндпоинт зависимостей проекта

## Контекст

`ProjectPage` собирает зависимости N+1 запросами `/api/tasks/{id}`
(`blocked_by`). Нужен один эндпоинт, отдающий пары зависимостей проекта.

## Шаги

1. `features/tasks/repository.py`: выборка связей blocker→task для задач проекта
   с ownership.
2. `features/tasks/router.py`: `GET /api/tasks/dependencies?project_id=`
   → `[{source, target}]`.
3. `features/tasks/service.py`: валидация project_id и сборка пар.
4. `viewer/src/shared/api`: тип и функция `taskDependencies(projectId)`.
5. `ProjectPage`: заменить N+1 на один запрос.
6. Тесты API: пары, пустой проект, чужой проект → 404.

## Acceptance

- Гант получает зависимости одним запросом.
- Чужой проект недоступен (404/пусто), ownership соблюдён.
- Проверки профиля зелёные.

## Проверки

`unit-tests`, `lint-python`, `typecheck-python`, `arch-python`,
`web-build`, `typecheck-web`, `lint-web`, `arch-web`.

## Scope

`app/features/tasks`, `viewer/src/pages/projects`, `viewer/src/shared/api`,
`tests/test_tasks*.py`.

## Риски

- Повторяющиеся/циклические связи: отдаём как есть, циклы отсекаются на уровне
  бизнес-логики задач (существующий код).
