# План T-EBDB7D0F — Тосты ошибок и локальная панель уведомлений

## Контекст

Сейчас ошибки показываются inline (`ErrorNote`, `setSendError`) и
теряются при переходе между экранами. Владелец просит: **любая**
ошибка — в тост, и одновременно в панель уведомлений **в браузере**
(`localStorage`, без серверного хранения), просмотренные уведомления
пользователь может закрыть.

## Шаги

1. `shared/ui`: очередь тостов (success/info/warn/error) с автозакрытием
   и `role="status"`/`role="alert"`, стек снизу справа, не перекрывает
   композер чата.
2. `shared/lib/notifications.ts`: локальное хранилище (JSON в localStorage,
   версия схемы, лимит 50 записей), API `add/read/dismiss/clear`,
   подписка через `useSyncExternalStore`.
3. Колокольчик в верхней панели: счётчик непрочитанных, панель-остров со
   списком (дата, тип, текст), «Прочитать все», закрытие отдельной записи,
   пустое состояние; `aria-live` для счётчика.
4. Централизованно: обёртка `api()` при ошибке кладёт тост и запись в
   панель один раз (дедуп по `errorMessage` + `location.pathname`),
   убирает разрозненные `ErrorNote`-пути, оставляя inline только для форм.
5. Светлая/тёмная тема, клавиатура (Esc закрывает панель), фокус-ловушка.

## Acceptance

- любая пойманная ошибка API даёт ровно один тост и одну запись в панели;
- закрытая запись не возвращается после перезагрузки, «Прочитать все»
  обнуляет счётчик; панель не обращается к серверу;
- axe 0, e2e-селекторы не ослаблены, ручной сценарий описан в отчёте.

## Scope

- `web/src/shared/ui/**` (тост-очередь, панель, колокольчик),
- `web/src/shared/lib/**` (хранилище уведомлений),
- `web/src/app/AppShell.tsx` (колокольчик), `web/src/shared/api/index.ts`
  (централизованная обработка ошибок), `web/e2e/**`.

Не трогаем: серверные `notifications`, другие страницы.

## Проверки

Профиль проекта (все обязательные): `web-build`, `typecheck-web`, `lint-web`,
`arch-web`, `e2e`, `a11y`, `unit-tests`, `lint-python`, `typecheck-python`,
`arch-python`. **Профиль и CI теперь совпадают**: `lint-python` включает
`ruff format --check` (коммит `d7e5b99`), расхождение устранено.

## Риски

1. Двойные тосты (глобальный обработчик + локальный `catch`) — решить
   дедупом и явными «немыми» вызовами.
2. localStorage может быть переполнен/запрещён (приватный режим) —
   деградировать в память без падений.
3. Тост поверх композера чата ухудшает ввод — позиция и `pointer-events`
   проверяются на `/chat`.
