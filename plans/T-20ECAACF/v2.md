# План T-20ECAACF — Проекты: дерево по сферам с колонковыми фильтрами

## Контекст

Сейчас `/projects` — плоская antd `Table`. Владелец просит дерево с
группировкой по сферам, сортировку по статусу/времени в каждой колонке
и фильтры в колонках: enum-мультивыбор «показать/скрыть» (например
показывать только активные и входящие, скрывать выполненные и
отменённые).

## Шаги

1. Заменить таблицу на `TreeList` (существующая обёртка antd `Tree`):
   уровень 1 — сферы (иконка/цвет, счётчик), уровень 2 — проекты.
2. Шапка дерева: колонки «Проект», «Статус», «Срок», «Прогресс» с
   сортировкой (`aria-sort`, клик по заголовку, стабильные сортировки
   внутри сфер), по умолчанию по сроку.
3. Фильтр-попап в колонке «Статус»: мультивыбор enum-значений с режимом
   «показать только»/«скрыть» (два сегмента), счётчики, «Сбросить».
4. Поиск по названию сферы/проекта (общий фильтр сверху), сохранение
   фильтров в URL (`?status=...&sort=...`) — ссылку можно переслать.
5. Пустые состояния: нет проектов / всё скрыто фильтром (с кнопкой
   «Сбросить»).

## Acceptance

- группировка по сферам, сортировка по каждой колонке работает и
  отражается в `aria-sort`;
- enum-фильтр поддерживает «показать только» и «скрыть» с мультивыбором,
  состояние переживает перезагрузку (URL);
- axe 0, e2e на дерево и фильтры, светлая/тёмная темы.

## Scope

- `web/src/pages/projects/**` (Projects + layout + сорт/фильтры),
- `web/src/shared/ui/**` (если нужна колонковая шапка дерева — обёртка),
- `web/e2e/**` (сценарии фильтра/сортировки).

Не трогаем: `pages/projects/ui/ProjectPage.tsx` (кроме дерева задач),
бэкенд.

## Проверки

Профиль проекта (все обязательные): `web-build`, `typecheck-web`, `lint-web`,
`arch-web`, `e2e`, `a11y`, `unit-tests`, `lint-python`, `typecheck-python`,
`arch-python`. **Профиль и CI теперь совпадают**: `lint-python` включает
`ruff format --check` (коммит `d7e5b99`), расхождение устранено.

## Риски

1. Фильтры «показать/скрыть» — два состояния на одно значение: UI должен
   явно показывать режим, иначе пользователь путается.
2. Дерево с сортировкой по колонкам конфликтует с группировкой:
   сортируем проекты внутри сферы, сферы — по названию.
3. Пересборка antd `Tree` на каждом изменении фильтра может быть тяжёлой
   при сотнях проектов — использовать `treeData` + memo.
