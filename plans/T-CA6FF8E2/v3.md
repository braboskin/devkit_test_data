# T-CA6FF8E2 — M3 follow-up: UI агента + A15/A16 (пауза сценария, сабагенты)

Черновик плана v3 (replan). Задача `T-CA6FF8E2` (feature, эпик `E-46E212B4`).
Изначально — UI-слой M3; по решению владельца 2026-11-21 в неё добавлены
backend-пункты A15 и A16 (размер L → **XL**, scope расширяется на backend).
**v3** добавляет второй раунд правок по ручному чеку владельца: учёт usage
сабагентов в токенах/стоимости, конфиг OAuth Яндекса
(`GET /api/settings/yadisk/config`) и инлайн-обработка текстовых PDF до
200 стр / 50 МБ (env). Это затрагивает M2-документы и настройки
Яндекс.Диска — scope расширен осознанно; серверный OCR/сканы — отдельная
задача `T-46BE9A0F`.
Карточку задачи отредактировать нельзя (в web нет формы, CLI-команды правки
нет), поэтому контракт по scope/размеру задаёт **этот план**; расхождение
метаданных карточки фиксируется как ограничение тулинга и отмечается на
гейтах/в отчёте.
