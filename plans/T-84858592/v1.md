# План: дизайн-система на обёртках antd

## Контекст

- antd 6 установлен и настроен (`ConfigProvider`, тема, CSS-переменные), но
  импортируется только в `AppShell`, `SearchOverlay`, `ThemePanel`. Экраны S2
  собраны на голом HTML (`input`, `button`, `dialog`) — противоречит правилу
  «свои компоненты на основе antd, расширяемые дальше».
- ТЗ §8: страницы не импортируют antd напрямую — только `shared/ui`.
- S3 (доска/гант/дерево) должен строиться уже на обёртках, поэтому задача идёт
  до S3.

## Шаги

1. `shared/ui/controls.tsx` — свои компоненты на antd с пробросом `name`
   (формы остаются на FormData), `id`, `aria`, `className`, `ref`:
   `Button` (primary/secondary/ghost/danger), `IconButton`, `TextField`,
   `TextAreaField`, `NumberField`, `SelectField` (options), `CheckboxField`,
   `SwitchField`, `DateField` (DatePicker, конвертация dayjs ↔ настенное время),
   `ColorField` (ColorPicker), `SearchField`.
2. `shared/ui/overlay.tsx`: `Modal` (свой API: title/open/onClose/footer/size),
   `Drawer`, `Confirm` через `App.useApp()`.
3. `shared/ui/surface.tsx`: `Card`/`Panel` (заголовок + действия, наши токены),
   `Tabs` (antd Tabs), `Empty` (antd Empty), `Spinner` (antd Spin), `Alert`
   (antd Alert). `EmptyState`/`Loading`/`ErrorNote` переводим на них с
   сохранением текущего API, чтобы старые страницы не трогать.
4. `shared/ui/table.tsx`: `Table` (antd Table) с нашими токенами, пустым и
   загрузочным состоянием — для списков; тяжёлые таблицы не переводим.
5. `shared/ui/toast.tsx`: `ToastProvider` (antd App) + `useToast`
   (`success/error/info`) как замена самодельным `Note`.
6. Перевести экраны S2 на обёртки: `home`, `spheres` (+detail), `projects`
   (+project page), `profile`, `files` (+file page), `search`, `notifications`,
   и модалку события календаря (native `<dialog>` → `Modal`). Коммит по экрану,
   приёмка после каждого.
7. Правило закрепить: `grep "from 'antd'"` в `pages`/`shared` — только
   `shared/ui/*`; Steiger должен остаться зелёным.
8. Проверки и отчёт.

## Acceptance

- Ни одна страница (`pages/**`) не импортирует antd напрямую; antd — только в
  `shared/ui` и `app`.
- Кнопки, поля, селекты, даты, цвета, модалки, табы, карточки, пустые/загрузка/
  ошибки на экранах S2 — наши компоненты из `shared/ui`.
- Поведение форм не изменилось (FormData, настенное время, те же API).
- Визуал не разъехался: тёмная/светлая тема, стекло, 44px таргеты, фокус.
- Компоненты расширяемы: проброс `className`/`style`/`ref`, единые пропсы,
  документированный экспорт через `shared/ui/index`.
- Проверки профиля зелёные, ноль подавлений.

## Проверки

`web-build`, `typecheck-web`, `lint-web`, `arch-web`, `format-web` — с exit code
в отчёт; плюс grep-проверка импортов antd.

## Scope

`viewer/src/shared/ui`, `viewer/src/pages`. `package.json` (зависимости уже
стоят), бэкенд — не трогать.

## Риски

- **Большой диф** по 8 экранам: коммит на экран, откат отдельного экрана
  возможен независимо.
- **Обратная совместимость** `EmptyState`/`Loading`/`ErrorNote`: API сохраняем,
  старые страницы (tasks/settings/jobs/chat/…) остаются как есть до S4.
- **DatePicker и timezone**: dayjs ↔ настенное время; проверять сохранение
  события и фильтры.
- **Modal-порталы** и стекло: backdrop-filter и тёмная тема — проверить на
  модалке события и формах.
- **Table-обёртка** не должна подменить тяжёлые списки (файлы/задачи): это
  по-прежнему списки/деревья, не antd Table.
