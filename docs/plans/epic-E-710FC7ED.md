последовательно по зависимостям, каждая в своей ветке `devkit/<task-id>`.
Макеты-референсы (не в репозитории): `.tmp/design/mockup.html`,
`.tmp/design/out/graphite-*.png` — Graphite, обе темы, акцент-пресеты.

## 1. Цель и критерии готовности

**Цель:** единая дизайн-система на всех экранах (Graphite + стекло, Roboto
Condensed, Emotion, LazyMotion), рабочий deep link и страница 404, подключение
модели с провайдером и списком моделей с сервера, каталог фронтенда называется
`web/`.

**Готовность эпика:** выполнены Acceptance A1–A10 из ТЗ; обязательные проверки
профиля (`web-build` → … → `arch-python`) зелёные на последнем коммите каждой
задачи; e2e и axe проходят; `rg -i viewer repo/atlas` не даёт живых ссылок.

`devkit.yaml` (корень data-репозитория). Так `AGENTS.md`, `README.md` и

### Порядок и параллельность

```
T-4FC8A97B ──┬─> T-D24FD0BF ──┬─> T-F4778357
             │                └─> T-7E446096
             ├─> T-59D31937
             ├─> T-7805803A
             └─> T-28C2A79F
                                все ──> T-EAD5B055
```

После M1 задачи M2 и M4–M5 независимы по файлам и могут идти в любом порядке;
лента T-8 включает переименование последней, чтобы не переписывать пути в
незакрытых задачах.

Почему переименование последним: оно механически трогает `app/backend/main.py`,
`tests/**`, CI и docs — те же файлы, что и остальные задачи. Перенос
переименования вперёд увеличил бы конфликтную поверхность, не давая
функционального выигрыша.

## 5. Риски и как снимаем

| Риск | Действие |
|---|---|
| Чужие виджеты (antd/SVAR/FullCalendar) не на Emotion | `vendor.ts` в T-4FC8A97B; вендорные темы закрываются в T-7805803A, при расхождении — отдельная задача с расширением scope через `replan` |
| Контраст стекла ломает axe | текстовые поверхности ≥ .9 непрозрачности; axe-тест на 5 маршрутах + 404 гоняется в каждой экранной задаче |
| Тесты читают исходники литералами (`test_web_build`, `test_viewer_acceptance`) | тексты и структуру сохраняем; при необходимости ассерты обновляются с владельцем, без `skip` |
| Вес бандла | `LazyMotion`/`m`, 3 веса woff2 с subsetting, шрифты и живут в SW-кэше статики |
| Шрифт недоступен офлайн для сборки | woff2 из `@fontsource/roboto-condensed` (OFL) кладутся в `viewer/public/fonts`; при недоступности пакета — владелец предоставляет файлы |
| Порядок задач | зависимости зафиксированы в devkit; пересечение scope (`shared/ui/**`, `Settings.tsx`) идёт только парами «зависимая → зависимость» |
