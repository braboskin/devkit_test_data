## Что сделано

M1 выполнен в согласованном объёме: фундамент + люди + PM + календарь + PWA
(PM/календарь перенесены из M4 решением владельца; M4 = напоминания/push).

- PostgreSQL-рантайм: `psycopg`, Alembic `0001_m1`, 13 таблиц §7, индексы,
  FK/каскады; `owner_id` на всех доменных сущностях (кроме join-таблицы
  `task_dependencies`, где изоляция идёт через `tasks`, и системных
  `users`/`sessions`); SQLite-варианты типов для тестов; compose с postgres:17.
- Вход: cookie-сессии scrypt, 30 дней со **скользящим продлением**: при
  продлении серверной сессии cookie перевыставляется (Max-Age 30 дней), не
  чаще раза в сутки; без ролей; `POST /api/auth/login|logout`, `GET /api/me`,
  `/health`.
- Изоляция: единая точка `ownership.get_owned_or_404`, фильтр `owner_id` на
  каждом маршруте; чужой id → 404; матрица 40 anon-маршрутов → 401,
  27 foreign-id маршрутов → 404.
- Сферы/проекты: CRUD, GET by id, перенос проекта, 409 при удалении связанных
  сущностей (проекты/задачи/события).
- Люди: CRUD, контакты/теги/заметки, привязки к сферам/проектам с ролью,
  карточка со связями (сферы, проекты, события, задачи), поиск, каскадное
  удаление связей.
- PM: задачи, подзадачи, `blocked_by` (409 при переходе в `doing`), RRULE
  (нормализация `RRULE:`-префикса) с созданием следующего экземпляра,
  фильтры/сортировка, связи с людьми.
- Календарь: события, повторения, участники-люди, `.ics` по RFC 5545
  (folding 75 октетов, all-day exclusive DTEND, экранирование), подписка с
  отзываемым токеном.
- PWA/UI: React + TypeScript + Vite (`viewer/**`), экраны входа, сфер/проектов,
  людей, задач, календаря; manifest, service worker, офлайн-оболочка, иконки;
  `viewer/dist` отдаётся FastAPI. Офлайн-навигация отдаёт `offline.html`, а
  сетевая ошибка `/api/me` показывает офлайн-экран с «Повторить», не форму
  входа.
- Профиль: новые модули в `unit-tests`, проверка `web-build`.

Блокеры независимого скептика исправлены в `9b1ca5b` (cookie при продлении),
`5fdc71c` (нормализация RRULE в задачах), `9aed37d` (RRULE в событиях/ICS);
замечание приёмки по офлайну — `7c6b3aa` (offline shell вместо логина).

## Риски

- Установка PWA на реальное устройство и импорт `.ics` в Apple/Google/Outlook —
  ручная приёмка (A6/A12) владельцем; офлайн-оболочка проверена на этой машине.
- Старый service worker у пользователя обновится при следующем онлайн-открытии;
  для проверки — Update/Unregister в DevTools (иначе возможен старый кэш).
- API-тесты идут на SQLite; PostgreSQL покрыт smoke-тестом миграции, не API.
- `schema-check` проверяет legacy-схему `kb`, а не новые таблицы.
- Время хранится naive UTC, UI показывает «настенное» время без конвертации —
  возможен сдвиг вне UTC+0.
- `task_dependencies` без `owner_id` — по §7 ТЗ, изоляция через `tasks`; в
  плане формулировка «owner_id у всех доменных» — фактическое отклонение для
  join-таблицы зафиксировано здесь.
- Minor от скептика/тестировщика (не блокеры): счётчики 409 без `owner_id`
  (недостижимо через API), `TaskOut.owner_id`, нет лимита попыток входа,
  `reset-password` не инвалидирует сессии, `web-build` в профиле `required:
  false` (карточку в `in_progress` не отредактировать), `ingest-fixtures`
  красный из-за отсутствующих fixtures.
- Line-ending diff (107 файлов) остаётся в рабочем дереве и не коммитится;
  untracked/лишних файлов нет.
