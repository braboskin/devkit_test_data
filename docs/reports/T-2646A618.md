## Что сделано

M1 выполнен в согласованном объёме: фундамент + люди + PM + календарь + PWA
(PM/календарь перенесены из M4 решением владельца; M4 = напоминания/push).

- PostgreSQL-рантайм: `psycopg`, Alembic `0001_m1`, 13 таблиц §7 с `owner_id`,
  индексы, FK/каскады; SQLite-варианты типов для тестов; compose с postgres:17.
- Вход: cookie-сессии scrypt, 30 дней со скользящим продлением, без ролей;
  `POST /api/auth/login|logout`, `GET /api/me`, `/health`.
- Изоляция: единая точка `ownership.get_owned_or_404`, фильтр `owner_id` на
  каждом маршруте; чужой id → 404.
- Сферы/проекты: CRUD, GET by id, перенос проекта, 409 при удалении связанных
  сущностей (проекты/задачи/события).
- Люди: CRUD, контакты/теги/заметки, привязки к сферам/проектам с ролью,
  карточка со связями (сферы, проекты, события, задачи), поиск по имени/тегу,
  каскадное удаление связей.
- PM: задачи (статусы, приоритет, срок, теги), подзадачи, `blocked_by`
  (409 при переходе в `doing`), RRULE с созданием следующего экземпляра,
  фильтры/сортировка, связи с людьми.
- Календарь: события (весь день, место, повторения), участники-люди,
  `.ics` по RFC 5545 (folding 75 октетов, all-day exclusive DTEND),
  подписка на календарь с отзываемым токеном.
- PWA/UI: React + TypeScript + Vite (`viewer/**`), экраны входа, сфер/проектов,
  людей, задач, календаря; manifest, service worker, офлайн-оболочка, иконки;
  сборка `viewer/dist` отдаётся FastAPI.
- Профиль проекта: в `unit-tests` включены новые модули, добавлена проверка
  `web-build`.

## Риски

- `.ics` в Apple/Google/Outlook и установка PWA на реальные устройства —
  ручная приёмка, автоматически не проверены (A6/A12).
- `schema-check` проверяет legacy-схему `kb`, а не новые таблицы; PG-специфика
  новых таблиц покрыта только smoke-тестом миграции, не API-тестами на PG.
- Время хранится naive UTC, UI показывает «настенное» время без конвертации —
  возможен сдвиг для пользователей вне UTC+0.
- Задача L/XL: четыре гейта (`code`, `test`, `architecture`, `security`) должны
  поставить независимые роли; на момент отчёта гейты ещё не выставлены.
- `ingest-fixtures` красный из-за отсутствующих fixtures (не M1).
- Латентные замечания WS-E: счётчики 409 при удалении сфер/проектов не
  фильтруют по `owner_id` (недостижимо через API), `TaskOut.owner_id` отдаётся
  в ответе (id самого пользователя).
- Line-ending diff (107 файлов) остаётся в рабочем дереве и не коммитится —
  проверено: untracked/лишних файлов нет.
