# T-84858592 — Дизайн-система: обёртки antd в shared/ui

## Что сделано

- **Контролы** (`shared/ui/controls.tsx`) на antd, со своим API и пробросом
  `name` для FormData, `id`, `aria`, `className`: `Button`, `IconButton`,
  `TextField`, `TextAreaField`, `NumberField`, `SelectField`, `CheckboxField`,
  `SwitchField`, `DateField`, `ColorField`, `SearchField`. Для контролов без
  нативного `input` (`Select`, `DatePicker`, `ColorPicker`, `InputNumber`,
  `Switch`) добавлен скрытый input, поэтому существующие формы на FormData не
  менялись.
- **Оверлеи** (`shared/ui/overlay.tsx`): `Modal` (свой API, наши кнопки),
  `useConfirm` через `antd App`.
- **Поверхности** (`shared/ui/surface.tsx`): `Card`, `Tabs`, `EmptyState`,
  `Spinner`, `Alert`. Старые `EmptyState`/`Loading`/`ErrorNote` переведены на
  antd с сохранением API — старые экраны не сломались.
- **Таблица** (`shared/ui/table.tsx`): `Table` на antd для списков.
- **Тосты** (`shared/ui/toast.tsx`): `ToastProvider` + `useToast` (message),
  провайдер добавлен в корень приложения.
- Токены antd: `controlHeight = 44`, `controlHeightSM = 36` (таргеты), темы и
  тёмный режим наследуются от `ConfigProvider`.
- **Экраны S2 переведены на обёртки**: Главная (состояния), Сферы (+страница
  сферы), Проекты, Профиль (форма контекста, кнопки, чекбокс «передавать
  агенту»), Файлы (+карточка файла: кнопки, confirm вместо `window.confirm`),
  Поиск, Уведомления, модалка события календаря (native `<dialog>` → `Modal`,
  поля → `TextField`/`DateField`/`SelectField`/`NumberField`/`CheckboxField`).
- `pages/**` больше не импортируют antd напрямую — только `shared/ui` и `app`
  (проверено grep: вхождений `from 'antd'` в `pages` нет).

## Риски

- **Бандл вырос до 448 kB gzip**: полный antd-набор контролов (DatePicker,
  ColorPicker, Select). Мера при необходимости — `lazy()` на тяжёлые экраны.
- **FormData-совместимость** скрытых input'ов: для `Select/Date/Number` в форме
  значение приходит строкой; `DateField` форматирует в `YYYY-MM-DDTHH:mm:ss`,
  настенное время. Проверять при новых формах.
- **`CheckboxField`** полагается на нативную отправку antd Checkbox (name/value
  `on`); в модалке календаря это сохранено.
- **Старые экраны** (tasks/settings/jobs/chat/agents/login/onboarding/documents)
  остаются на нативном HTML до S4 — осознанно, чтобы не раздувать диff.
- **S3 и дальше** обязаны использовать эти обёртки; прямое импортирование antd
  в страницах — нарушение правила.
