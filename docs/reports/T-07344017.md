- **F9 индексация**: прямые импорты вместо `importlib`-хуков; сбой виден
  (`error='indexing failed'`) в VPS- и worker-пути; `POST /api/documents/{id}/reindex`.

## Риски

- **F11 live** не проверен: нужны `YANDEX_CLIENT_ID/SECRET/REDIRECT_URI` на
  сервере и Redirect URI в приложении Яндекса; тесты — mock token-endpoint.
  После настройки — ручная проверка одной кнопкой.
- **F1**: SNI/TLS проверены на fake-stream/httpcore, реальный handshake/сертификат
  не гонялся; SSRF DNS-rebinding закрыт pinned-подключением, но нужен
  независимый пентест при желании.
- Миграция 0003 создаёт partial unique index только в Alembic; в
  `models.Base.metadata` индекс не объявлен — возможен drift при autogenerate
  (follow-up: добавить `Index(...)` в `models.py`).
- H1: callback при неверном state отдаёт 303 `/?yadisk=error` (UX), а не 400
  из брифа; обмен code не выполняется, интеграция не создаётся — принято как
  осознанный контракт, зафиксировано в тесте.
- `--concurrency` при одном worker-токене и single-flight даёт мало выигрыша;
  польза — разные владельцы/процессы.
- Реальные BGE-M3/Qdrant — принятое ограничение (owner decision).
- `_drop_index` при удалении по-прежнему не валит запрос при сбое Qdrant
  (только лог) — возможны stale-точки.
- UI проверен сборкой/smoke, не браузерным E2E.
