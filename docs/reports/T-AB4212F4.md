# T-AB4212F4 — Главная, Развитие, Профиль, Интересы, Проекты, Люди

## Что сделано

- **Главная** (`pages/home`): виджеты «Сегодня», «Ближайшие события»,
  «Входящие» (задачи без интереса и проекта), «Развитие» (цели/привычки/
  метрики), «Файлы», уведомления, быстрые ссылки; скелетоны и пустые состояния.
- **Интересы** (`pages/interests`): список карточек с цветом и описанием,
  создание (название, цвет, описание), страница интереса — summary (проекты,
  задачи/done, люди, файлы), проекты, задачи без проекта, файлы, редактирование
  названия/цвета/описания.
- **Проекты** (`pages/projects`): список с интересом и статусом, создание,
  базовая карточка проекта (summary + задачи). Доска, гант и таймлайн — S3
  (T-366AA68F), страница используется как временная.
- **Профиль** (`pages/profile`): загрузка фото (`uploadAvatar`, версия в URL от
  `Date.now()`), контекст для агента (имя, возраст, город, профессия) в
  `UserProfile.data.context`, тумблер «передавать агенту», `ThemePanel`, ссылки,
  выход.
- **Люди**: `PageHeader`, аватары в списке, загрузка фото в карточке
  (`uploadPersonPhoto`), deep link `/people/{id}` открывает карточку человека
  (связи, контакты, задачи, события — существующая карточка).
- **Развитие**: заголовок страницы и навигация по разделам (Цели · Привычки ·
  Метрики · Дневник · Обзоры) через якоря к существующим секциям; логика API не
  менялась.
- **Роутер**: `/` → Home, `/interests`, `/interests/:id`, `/projects`,
  `/projects/:id`, `/people/:id`, `/growth`; старые страницы не удалены.
- `Person.photo_ref` добавлен в TS-тип (бэкенд отдаёт поле с S1).

## Риски

- **Развитие**: табы — навигация по якорям, а не переключение секций. Монолит
  `Growth.tsx` (1178 строк) не переписывался, чтобы не смешивать переработку UI
  и бизнес-логику. Полные табы — отдельная задача.
- **Главная** делает 7 параллельных запросов и фильтрует на клиенте; для
  персональных объёмов приемлемо, при росте — общий endpoint дашборда.
- **Люди**: страница осталась одним компонентом с карточкой; deep link
  открывает карточку, но отдельного экрана человека с вкладками нет (S3/S4).
- **Аватары людей** кэшируются браузером: URL без версии, после загрузки нужен
  `?v=`. У профиля версия уже есть.
- **Проект**: страница проекта временная, её заменит T-366AA68F (дерево/доска/
  гант).
- Name/avatar пользователя по-прежнему только в `UserProfile.data.context` и
  `users.avatar_ref`; отдельного PATCH `/api/me` нет — имя в шапке берётся из
  `username`, пока не появится эндпоинт.
