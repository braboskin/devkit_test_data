## Что сделано

1. Оболочка (`web/src/app/AppShell.tsx`) — три независимых острова на desktop:
   - левый сайдбар — стеклянная плашка (радиус 22, внутренний блик, тень);
     бренд «Atlas», группа «Основное» (Главная/Развитие/Чат/Календарь), подпись
     «Система» (Сферы/Проекты/Задачи/Люди/Файлы), внизу — блок «Индекс знаний»;
   - верхняя панель — поисковый остров по центру (480 px на широком экране,
     420 px на 900–1039 px) и правый остров профиль/уведомления
     (колокольчик со счётчиком + аватар);
   - контент между островами, фон `Canvas` просвечивает.
2. «Настройки» убраны из сайдбара. Вход остался в меню профиля и добавлен в
   палитру `Ctrl+K` (`web/src/app/SearchOverlay.tsx`, блок «Перейти»).
3. Токены `--island-*` только в `web/src/app/styles/tokens.css`:
   `--island-bg`, `--island-border`, `--island-highlight`, `--island-shadow`,
   `--island-blur`, `--island-radius` — значения тёмной и светлой тем строго по
   R6.3 (вариант «Графит», блик 3 %). Магических `rgba` по компонентам нет.
4. `prefers-reduced-transparency: reduce` → непрозрачный фон островов, без
   blur; `data-effects="off"` также даёт плотный fallback.
5. Адаптивность (уточнение владельца от 28.11):
   - ≥1024 px — полный сайдбар;
   - 768–1023 px (планшет) — свёрнутый сайдбар-рейл 72 px: иконки без подписей
     (имена доступны скринридеру), «Индекс знаний» — иконкой внизу;
   - <768 px (мобильный) — сайдбара нет; сверху только остров поиска, снизу
     стеклянный остров-табы **Home / Chat / Space / Profile** (иконка+подпись,
     активный — акцент), у Profile — счётчик непрочитанных; контент получает
     нижний отступ с `safe-area-inset-bottom`.
6. e2e: три острова и зазоры по bounding box на 1440/900/390 px; «Настройки»
   нет в сайдбаре и есть в меню профиля; `Ctrl+K` открывает палитру; на 900 px
   рейл и отсутствие нижних табов; на 390 px — табы Home/Chat/Space/Profile,
   переходы Space и Profile, отсутствие сайдбара; axe дополнительно в тёмной
   теме и на 390 px.

## Риски

1. На мобильном счётчик на табе Profile пока берёт серверный
   `/api/notifications`; в `T-EBDB7D0F` он переключится на локальную панель.
2. `env(safe-area-inset-bottom)` даёт 0 без `viewport-fit=cover` в `index.html`;
   `index.html` вне scope этой задачи — на устройствах с «челкой» отступ
   останется базовым 10 px (не перекрывает таб-бар).
3. `backdrop-filter` на слабом GPU не измерялся по FPS; проверена только
   корректная отрисовка и отсутствие ошибок.

## Что не проверено

1. Живой стенд (`start-atlas.ps1`) визуально не снимался: скриншоты сделаны на
   собранном `dist` с моками API, как принято в e2e проекта.
2. Реальный планшет/телефон (Safari iOS, Android Chrome) и safe-area не
   проверялись — только Chromium 1440/900/390.
