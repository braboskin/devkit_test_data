# T-7F821446 — Календарь Apple Calendar

## Что сделано

- `shared/ui/calendar.tsx` — тонкая обёртка FullCalendar 6.1.22 (пин из S0):
  плагины dayGrid, timeGrid, interaction, multiMonth; `ru`-локаль, без
  стандартного тулбара, `selectable`, `editable`, `dayMaxEvents`, недели с
  понедельника. События красятся цветом интереса, drag/resize/select отдают
  колбэки, `datesSet` — диапазон для загрузки.

  новых зависимостей нет), «‹ / Сегодня / ›», вид и дата в URL

  чекбоксами (скрытые календари в localStorage).

  раскрываются сервером), создание кликом/протяжкой, редактирование по клику,

- Форма события — нативный `<dialog>` (фокус, Esc, backdrop), без модалок antd

- Мобильный: сайдбар уходит под календарь, сетка в одну колонку.

## Риски

- **Вес бандла** вырос до 391 kB gzip: FullCalendar + multimonth. Для
  админ-панели приемлемо; если станет критично — `lazy()` на маршрут календаря.
- **RRULE-серии**: правка меняет всю серию, исключений (EXDATE) API не умеет;
  вопрос «это / будущие / все» из ТЗ не реализован — нужен бэкенд-эндпоинт.
- **Участники события** в форме не редактируются (есть отдельный API
  `/participants`, UI — следующий шаг).
- **Время**: событие хранится настенным временем; FullCalendar работает в
  локальной зоне, конверсия `toServer` обрезает зону. Переходы DST проверять.
- **Agenda** — свой список, а не полноценный list-view FullCalendar; сортировка
  по началу, без группировки по дням.
- Мини-месяц не показывает точки событий (только навигация) — косметика,
  отдельным шагом при желании.
