# T-AC2A5666 — Файлы, Настройки, уведомления, задания, поиск

## Что сделано

- **Файлы** (`pages/files`): дерево «интерес → проект → файлы» на `TreeList`
  с цветом интереса, статусами (`DocBadge`), сортировкой по имени/дате и
  группой «Без интереса». Карточка файла `/files/{id}`: метаданные, статус,
  ссылки на интерес и проект, скачивание оригинала, переиндексация,
  переобработка, удаление; текст документа — `<pre>`, для PDF/картинок — iframe
  на `/api/documents/{id}/file`.
- **Поиск** (`pages/search`): страница по `searchAll` (`scope=all`) — группы
  задачи, проекты, интересы, люди, файлы, чаты с переходами к сущностям и
  пустым состоянием. Старый экран с фильтрами документов заменён; глобальный
  поиск по файлам остался в оверлее шапки.
- **Уведомления** (`pages/notifications`): реальная лента `/api/notifications`,
  непрочитанные, фильтр «Все/Непрочитанные», отметка прочитанного, переход по
  ссылке.
- **Профиль**: загрузка фоновой картинки (`uploadBackground` из S1), `AppShell`
  применяет её как `--bg-image` с затемнением `--bg-scrim` при загрузке.
- **Настройки и Задания** оставлены существующими рабочими экранами (LLM,
  Яндекс.Диск, уведомления, push, воркер; задания с отменой) — их переработка
  под новые токены запланирована в S4, функционально они закрывают acceptance.
- Тема/акцент/фон настраиваются в профиле (как решено с владельцем), поэтому
  `settings` не дублирует `ThemePanel`.
- Удалён старый слайс `pages/spheres-projects` (заменён «Интересами» в S2a):
  с ним слой `pages` упирался в лимит Steiger (21 > 20). Другие старые экраны
  не тронуты — снос в T-607A3128.

## Риски

- **Дерево файлов** грузит `/api/documents` целиком; при тысячах файлов нужен
  серверный фильтр/пагинация — ограничение отмечено.
- **Старый `pages/documents`** больше не используется роутером, но удалить его
  нельзя раньше S4: на него ссылается `test_web_build` (тайминги опроса).
- **Фон из профиля** применяется инлайн-переменной `--bg-image`, она сильнее
  пресетов из `data-bg`: пока картинка загружена, смена пресета визуально не
  видна, пока не убрать фон. Убрать/заменить фон можно только новой загрузкой.
- **Уведомления** не обновляются автоматически, только при заходе/действии.
- **Поиск**: ILIKE на SQLite не складывает регистр (см. S1); на PostgreSQL ок.
