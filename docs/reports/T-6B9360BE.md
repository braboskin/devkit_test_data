## Что сделано

- CI переименован в **Quality gates** и разделён на джобы:
  - `web`: `npm ci` → `web-build` → `typecheck-web` → `lint-web`
    (eslint + prettier) → `arch-web` (Steiger); публикует artifact
    `viewer-dist` из `viewer/dist`;
  - `python`: `needs: web`, скачивает `viewer-dist` в `viewer/dist`, затем
    `unit-tests` (`unittest discover -s tests`) → `lint-python`
    (ruff check+format) → `typecheck-python` (mypy) → `arch-python`
    (`tests.test_architecture`).
- UTF-8: `PYTHONIOENCODING=utf-8` + `chcp 65001` в `unit-tests`.
  `PYTHONUTF8=1` **не включаем**: на Windows он переключает декодирование
  `subprocess`, а PostgreSQL/скрипты печатают cp1251 — первый прогон CI упал
  на `UnicodeDecodeError` и `NoneType + str` в `test_migrations`/`test_search`.
  После фикса русский вывод читаем, тесты зелёные.
- Тесты сокращены и переименованы (см. «Изменения»): **446 → 435** тестов,

## Риски

- **Artifact `viewer-dist`**: python-джоб зависит от upload/download artifact
  на self-hosted runner; при сбое artifact job упадёт (не скипнет тест молча).
  Fallback — `npm ci && npm run build` в python-джобе; сейчас не включён.
- **Self-hosted runner один**: `web` и `python` выполняются последовательно;
  разделение даёт статусы, но не параллелизм.
- **Сокращение тестов**: 11 удалённых тестов были дублями/script-eval;
  P0/P1 сохранены, но повторная проверка покрытия — в ревью PR.
- **Отложенное слияние agent/ingestion-файлов**: список из 30 модулей длиннее
  целевого; если нужен жёсткий target ~18 — отдельный шаг с переименованием
  helpers.
- **CI dependency actions**: `upload-artifact@v4`/`download-artifact@v4`
  требуют доступ к GitHub Actions на runner; локально не воспроизводится.
- **Русский вывод**: проверен в скачанном логе CI; если GitHub UI покажет
  иначе — нужен отдельный пример/скрин.
