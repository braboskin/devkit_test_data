# T-6E58E324 — Онбординг: шаги с превью, пропуск, возобновление

## Что сделано

- `app/SetupWizard.tsx` переписан: 11 шагов — приветствие → модель → Яндекс.Диск
  → «О тебе» → сферы → цели → привычки → метрики → ритм → тон агента →
  приватность.
- **Превью перед созданием**: каждый шаг показывает блок «Создадим»; записи
  создаются только по «Утвердить», «Пропустить» идёт дальше без записи.
- **Возобновление**: прогресс (шаг, созданные элементы, флаг «опрос пропущен»)
  хранится в `localStorage` (`atlas.onboarding.v2`), после перезагрузки
  открывается тот же шаг; по завершении ключ удаляется.
- **Без дублей**: сферы создаются с проверкой существующих имён; повторный проход
  не плодит одинаковые сферы; остальные сущности создаются только по утверждению.
- **О тебе**: имя/возраст/город/профессия → `UserProfile.data.context`, тумблер
  «передавать агенту».
- **Пресеты сфер**: здоровье, работа, финансы, отношения, развитие, интересы,
  дом, отдых, смысл (+ свои через запятую).
- Модель: провайдер, адрес, модель, ключ, «Проверить подключение»; Диск: OAuth
  (кнопка скрыта/неактивна, если OAuth не настроен на сервере) или токен вручную,
  «Пропустить».
- «Пропустить опрос» доступен с шага «О тебе» и завершает настройку.
- Всё на компонентах `shared/ui` (antd-обёртки), бэкенд не менялся.
- Тест `test_ag18` обновлён: вместо `<Onboarding` проверяет шаг `'onboarding'`
  в новом визарде (старый диалоговый экран больше не используется; проверки
  llm/yadisk/«Позже»/«Пропустить» сохранены).

## Риски

- **Нет отдельных маршрутов** `/login`, `/setup/model`, `/setup/disk`, `/survey`:
  поток остался в гейте `App` → `SetupWizard` (11 шагов), deep-link на шаг
  невозможен; возобновление — через `localStorage`. Отдельные маршруты требуют
  перестройки гейта и проверки SPA/PWA — вынесено в S4.
- **Баннер «опрос пропущен» на Главной** не добавлен: «Пропустить опрос» сразу
  завершает настройку. Баннер — follow-up.
- **Мультивыбор пресетов** (сферы/привычки/метрики/приватность) — нативные
  чекбоксы внутри карточек, не `CheckboxField` из-за групповой раскладки;
  перевести на обёртку — в S4.
- **Идемпотентность** ограничена: id созданного не персистятся на сервере;
  защита — проверка имён сфер и `localStorage`. При полном сбросе возможно
  повторное создание целей/привычек/метрик.
- **Опрос 9 шагов** сгруппирован в 9 содержательных шагов (ритм/агент/приватность
  вместо трёх вопросов диалога); исходные адаптивные вопросы `/api/onboarding`
  не используются — старый экран `pages/onboarding` остаётся неиспользуемым до S4.
