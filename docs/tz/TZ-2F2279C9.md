# ТЗ: Дизайн-система Atlas и доработки фронтенда (pass 2)

Второй проход по фронтенду после эпика `E-AA7F23F1` (IA и каркас). Меняются
только оформление, роутинг и форма подключения модели. Данные и бизнес-логика
не меняются, кроме необязательного `api_key` в `PUT /api/settings/llm` и нового
эндпоинта списка моделей.

## Цель

Единая дизайн-система на всех экранах (Graphite + стекло, Roboto Condensed,
CSS-in-JS, анимации), рабочий deep link на любую страницу, честная 404,
выбор LLM-провайдера со списком моделей с сервера, переименование `viewer/` в
`web/`.

## Контекст

- `viewer/` — React 19.3 + Vite 8 + TS 7, FSD + Steiger, antd 6, SVAR kanban/gantt,
  FullCalendar 6.1.22, Recharts, Lucide. 15 слайсов в `pages/`.
- Стили — 7 `.css` файлов, 1431 строка: `base.css` 682, `shell.css` 486,
  `tokens.css` 122, `ui.css` 34, `calendar.css` 87, `files.css` 17, `styles.css` 3.
- Тема живая: `shared/lib/theme.ts` пишет в `<html>` `--accent`, `data-theme`,
  `data-effects`, `data-bg`; пресеты фона `none/aurora/mist/night` объявлены.
- Роутер — React Router 8.5.3, `createBrowserRouter`, wildcard уже уводит на `/`.
- Бэкенд монтирует `StaticFiles(html=True)` на `/` (`app/backend/main.py:142`),
  поэтому `GET /settings` отдаёт **404 JSON** — deep link не работает на сборке.
- LLM: каталог `viewer/src/shared/lib/llmProviders.ts` (deepseek/openai/openrouter/custom),
  селект провайдера только в `SetupWizard.ModelStep`; на `/settings` — два
  текстовых поля и `datalist` из двух моделей.
- `app/backend/features/agent/llm.py`: `client()`, `check()` (GET `models` → 200),
  `TRANSPORT` подменяется в тестах; `normalize_base_url` уже есть.
- `PUT /api/settings/llm` требует `api_key` всегда (`ApiKey` = min 8, без пробелов).
- Тесты читают исходники литералами: `tests/test_web_build.py` (строки
  `status === 401`, «Подключить Яндекс.Диск», подписи вкладок), `test_viewer_acceptance.py`.
  E2E: `e2e/shell.spec.ts` ищет класс `.ui-gantt`, `a11y.spec.ts` — 5 маршрутов.

## Решения владельца (зафиксированы, не переспрашивать)

| Вопрос | Решение |
|---|---|
| Палитра | Graphite: графитовые нейтрали, акцент выбирает пользователь |
| Акцент по умолчанию | `#334155` (графит); 8 пресетов из `theme.ts` остаются |
| Темы | светлая + тёмная + системная, axe-тест в обеих |
| Плотность | компактная: 14px тело, строки ~32px |
| Стекло | сильное: панели alpha ≈ .52, оверлеи .78–.97, blur 30/40 |
| CSS-in-JS | `@emotion/react` + `@emotion/styled`; компонентных `.css` не остаётся |
| CSS-переменные | один `tokens.css` остаётся источником токенов и рантайм-смены темы |
| Анимации | `motion` (LazyMotion + `m`) для маршрутов, панелей, списков; hover/focus — CSS |
| Шрифт | Roboto Condensed, self-host woff2 400/500/700 (OFL), на весь UI |
| Охват | сразу все страницы |
| Форма модели | один компонент в онбординге и настройках |
| Список моделей | новый эндпоинт на бэкенде (ключ не уходит в браузер) |
| Загрузка моделей | кнопка + авто-запрос по паузе после ввода ключа |
| Роутинг | SPA-fallback + страница 404 внутри оболочки |
| Переименование | всё консистентно: путь, npm-имя, CI-artifact, имена тестов, docs |

## Требования

### R1. Дизайн-система

#### R1.1 Токены (`viewer/src/app/styles/tokens.css`)

Группы: canvas (`--bg0/--bg1`, 2 glow от акцента), поверхности (`--surface`,
`--raised`, `--menu-bg`, `--sunken`, `--hover`), текст (`--text`, `--muted`,
`--faint`), линии (`--border`, `--border-strong`), семантика (`--accent`,
`--accent-soft`, `--on-accent`, `--ok`, `--warn`, `--danger`), тень
(`--shadow`), стекло (`--blur`, `--blur-raised`), радиусы, длительности.
Все токены существуют в светлой и тёмной теме (`body[data-theme="light"]`).

Правила: `--accent-soft` и glow — производные акцента через `color-mix`;
`data-effects="off"` → alpha 1, blur 0. Текст ≥ 4.5:1, крупный ≥ 3:1,
focus-ring ≥ 3:1 к соседнему фону.

#### R1.2 Слои

- S0 canvas — градиент + 2 радиальных glow по акценту, `fixed`.
- S1 shell — сайдбар 264px и топбар 60px: стекло, одна граница.
- S2 panel — секции и карточки: alpha ≈ .52, blur 30, radius 18, border, shadow.
  Вложенное внутрь панели — `--sunken` или прозрачное с разделителем.
- S3 overlay — dropdown, modal, toast: opacity .78–.97, blur 40, portal.
- Поля ввода, textarea, таблицы — плотный `--sunken` (≈ .9), не стекло.

#### R1.3 Типографика

Roboto Condensed 400/500/700 из `viewer/public/fonts/` (`@font-face` в Emotion
`Global`, preload 400, `font-display: swap`, fallback `Roboto, system-ui,
sans-serif`). Шкала 12/13/14/16/20/24/28; line-height 1.45 тело, 1.2 заголовки;
`font-variant-numeric: tabular-nums` для чисел и дат. Моноширинный — для кода.

#### R1.4 CSS-in-JS

`@emotion/react`, `@emotion/styled`, `motion` в dependencies. `shared/ui/theme.ts`
— тема Emotion (space, radii, durations, z-index) и хелпер `surface(level)`;
цвета только через `var(--*)`. Существующие публичные компоненты `shared/ui`
переводятся на Emotion **без смены публичного API** (`Button`, `Panel`,
`PageHeader`, поля, `Empty`, `ErrorNote`, `Loading`, `Toast`, `Modal`, `table`,
`board`, `calendar`). Удаляются `styles/shell.css`, `shared/ui/ui.css`,
`pages/calendar/ui/calendar.css`, `pages/files/ui/files.css`.
`styles/base.css` — legacy-слой для ещё не переведённых экранов: он удаляется
последней экранной задачей (T-7E446096), а не фундаментом, иначе экраны
остаются без стилей и e2e/a11y падают. К концу эпика `styles.css` содержит
только импорт `tokens.css`.
`docs/DESIGN.md` в репозитории фиксирует токены, слои, motion и правила.

#### R1.5 Каркас и страницы

`AppShell`: сайдбар (9 пунктов, активный — акцентная плашка + 2px индикатор),
топбар (поиск с `Ctrl K`, уведомления, аватар), glow-фон. `PageFrame`:
PageHeader (eyebrow/title/description/actions) → контент max-width 1280, gutter 24.
Все 15 слайсов переводятся на примитивы: Главная, Чат, Календарь, Сферы,
Проект, Задачи, Люди, Файлы, Поиск, Задания, Настройки, Агенты, Профиль,
Развитие, Space, Вход, Онбординг, 404.

Состояния: skeleton при загрузке, `Empty` с CTA, `ErrorNote` с повтором, тост.

#### R1.6 Motion

`LazyMotion` + `domAnimation`: смена маршрута (fade + 8px), появление панелей и
модалок (opacity + scale .98→1), списки (stagger 30ms, не больше 8 элементов),
тосты, drawer. Длительности ≤ 260ms, `--ease`. `prefers-reduced-motion` и
`effects=off` → анимаций нет. Анимация не задерживает ввод.

#### R1.7 Третьи лица

antd 6, FullCalendar, SVAR kanban/gantt, Recharts остаются; их темы и
переопределения — в одном `shared/ui/vendor.ts` (Emotion `Global`). Класс
`.ui-gantt` сохраняется (e2e). Стекло на теле таблиц и длинных списков не
применяется.

#### R1.8 Настройки: оформление

Секция «Оформление» на `/settings`: тема (Светлая/Тёмная/Системная),
акцент — 8 пресетов (дефолт `#334155`), «Эффекты и прозрачность»,
фон (Нет/Aurora/Mist/Night). Значения пишутся в `localStorage` и применяются
сразу, как сейчас.

#### R1.9 Готовые компоненты antd

antd — первый выбор для любого элемента, у которого есть готовый аналог с
клавиатурой, фокусом и a11y. Свой компонент допустим только там, где antd не
покрывает поведение или ломает дизайн (стекло, каркас, доменные обёртки).

Обязательно заменяются на antd: `Avatar` → `Avatar`; `Skeleton` и
`skeleton-line` → `Skeleton`; `Badge`/`DocBadge`/`JobBadge` → `Tag` (цвет из
tone); `TreeList` → `Tree`; `Empty` (`<p class="muted">`) → `Empty`; дубль
`EmptyState` из `States.tsx` удаляется (остаётся antd-версия из `surface.tsx`);
нативные `<select>`/`<input>`/`<textarea>`/`<button>` на экранах → обёртки
`SelectField`, `TextField`, `TextAreaField`, `NumberField`, `DateField`,
`Button`; `<input type="file">` → `Upload`; чекбоксы списков → `Checkbox`.

Добавляются по месту: степпер обучения — `Steps`; прогресс сфер и проектов —
`Progress`; «Дальше» на списке документов — `Pagination` (когда сервер отдаёт
total); статус-панели и трейсы — `Collapse`; мобильный сайдбар — `Drawer`;
иконочные кнопки топбара — `Tooltip`, меню профиля — `Dropdown`; 404 —
`Result status="404"`; выбор модели — `AutoComplete`; фильтры из 3–5 значений —
`Segmented`.

Остаются своими: `PageHeader` (в antd 6 вынесен в pro-components), `WidgetHost`,
`session`, `toast`/`overlay`/`table`/`surface`/`controls` (уже обёртки antd),
поверхности и стекло. `Form` не переводим: формы шлют `FormData`, смена на
antd Form — отдельный рефакторинг, не эта задача.

### R2. Подключение модели

#### R2.1 UI (один компонент)

`shared/ui` → `LlmSettingsForm`: провайдер (select: DeepSeek, OpenAI, OpenRouter,
Свой OpenAI-совместимый) → адрес API (только для «Свой»; для каталога
подставляется и показывается) → API-ключ (`type=password`, placeholder `sk-...`,
`autoComplete=off`) → модель (`AutoComplete`: подсказки из списка
провайдера и свободный ввод id для «Своего»), провайдер — `Select`. Кнопки: «Загрузить модели», «Проверить подключение», «Сохранить»;
в настройках — «Удалить ключ». Компонент используется в `SetupWizard.ModelStep`
и в секции «Модель» на `/settings`; провайдер выводится из сохранённого
`base_url` (не совпало с каталогом → «Свой»), в БД провайдер не хранится.

Поведение: список моделей грузится кнопкой и автоматически по паузе после ввода
ключа (~500 мс, не на нажатие); при ошибке — предупреждение и фолбэк на
статический каталог; ручной ввод остаётся всегда. Если ключ уже сохранён,
модель можно сменить без повторного ввода ключа.

#### R2.2 Бэкенд

- `POST /api/settings/llm/models`, тело `{base_url, api_key?}` →
  `{models: string[], detail: string|null}`; при пустом `api_key` берётся
  сохранённый (нет ключа → 400). Запрос к провайдеру — через
  `app.backend.features.agent.llm.client()` (`TRANSPORT` остаётся подменяемым в
  тестах), ответ разбирается как `data[].id`; отказ провайдера → 200 с пустым
  списком и `detail` (как `/llm/check`). Ключ не логируется и не возвращается.
- `PUT /api/settings/llm`: `api_key` необязателен; пустой — сохраняется прежний
  ключ, при его отсутствии 400. `base_url` нормализуется существующим
  `normalize_base_url`, `model` обязателен.
- Новый маршрут вносится в матрицу `tests/test_isolation.py` (собирается из OpenAPI).

### R3. Роутинг и 404

- `app/backend/main.py`: вместо голого `StaticFiles(html=True)` — подкласс,
  который на 404 отдаёт `index.html`; для `/api/**` и `/health` 404 остаётся
  JSON. Сборка ищется в `web/dist` (после R4; до R4 — `viewer/dist`).
- `pages/not-found/` — новый слайс: «Страница не найдена», показанный путь,
  кнопка «На главную»; маршрут `*` вместо `<Navigate to="/">`.
- Легаси-редиректы (`today`, `documents`, `interests`) сохраняются.
- Тесты: сборка с dist → `GET /settings` = index.html; `GET /api/nope` = JSON 404;
  e2e `/nope` → страница 404 → клик ведёт на `/`.

### R4. Переименование `viewer/` → `web/`

`git mv viewer web` и синхронная правка всех живых ссылок:

- `web/package.json` → `"name": "atlas-web"`, `package-lock.json`;
- `devkit.yaml` (7 `cwd`, setup `install-viewer` → `install-web`; имена проверок
  `web-build`, `typecheck-web`, `lint-web`, `arch-web`, `e2e`, `a11y`,
  `format-web` не меняются);
- `.github/workflows/ci.yml`: `working-directory`, artifact `viewer-dist` →
  `web-dist`, шаги upload/download;
- `.pre-commit-config.yaml`, `pyproject.toml` (`exclude`);
- `app/backend/main.py` (`ROOT / "web" / "dist"`, имя mount `web`);
- тесты: `test_viewer_acceptance.py` → `test_web_acceptance.py`, пути в
  `test_web_build.py`, `test_growth.py`, `test_app_auth.py`, `test_push.py`;
- `repo/atlas/AGENTS.md`, `README.md`, `app/README.md`.

`docs/coordination/archive/DEVKIT.md` — исторический документ, не переписывается.

## Acceptance

A1. К концу эпика один `.css` (`tokens.css`); компонентных стилей в файлах нет; `steiger`,
`tsc`, `eslint`, `prettier` зелёные.
A2. Roboto Condensed отдаётся с нашего origin (`public/fonts`), preload 400,
   `swap`; интерфейс не показывает невидимый текст до загрузки шрифта.
A3. Все 15 экранов + вход/онбординг/404 на примитивах: одинаковый PageFrame,
   один набор поверхностей; в тёмной теме нет светлых «белых» полей и
   нечитаемого текста; axe (serious/critical) = 0 на маршрутах `a11y.spec.ts`.
A4. `effects=off` даёт плотные поверхности и нулевой blur; `prefers-reduced-motion`
   отключает анимации; motion не блокирует ввод.
A5. Переходы между маршрутами, появление панелей/модалок и stagger списков
   реализованы через `motion`; hover/focus — CSS.
A6. Настройки: тема, акцент (дефолт `#334155`), эффекты, фон применяются сразу и
   переживают перезагрузку.
A7. Подключение модели: провайдер → (URL) → ключ (`sk-...`) → модели; список
   приходит с провайдера, при ошибке — каталог и ручной ввод; один компонент в
   онбординге и настройках; смена модели без повторного ввода ключа работает.
A8. Роутинг: на собранном фронте `GET /settings`, `/chat/1`, `/nope` отдают
   SPA-оболочку; `GET /api/nope` — JSON 404; `/nope` показывает страницу 404.
A9. `viewer` не встречается в живых ссылках (только архив); CI-artifact
   `web-dist`; `npm ci && npm run build` в `web/` зелёный.
A10. Обязательные проверки профиля и e2e/a11y зелёные; тесты, читающие исходники
   литералами, обновлены осознанно (не ослаблены).
A11. Самописных дублей antd не остаётся: `Avatar`, `Skeleton`, `Badge`,
   `TreeList`, `Empty`, дубль `EmptyState` заменены на antd-компоненты;
   на экранах нет нативных `<select>`/`<input>`/`<textarea>`/`<button>`
   и `<input type=file>` там, где есть обёртка; свои остались только
   `PageHeader`, `WidgetHost`, поверхности и обёртки.

## Ограничения

- Новые UI-зависимости — только `@emotion/react`, `@emotion/styled`, `motion`;
  шрифт вендорится файлами, рантайм-зависимости для него нет.
- Библиотеки только MIT/Apache/OFL; antd, SVAR, FullCalendar, Recharts, Lucide
  остаются и не заменяются.
- Язык интерфейса — русский, i18n не вводится.
- Ноль подавлений: без `eslint-disable`, `type: ignore`, `noqa`; проверки не
  ослабляются, тесты не удаляются.
- Минимальный diff, работа в ветке `devkit/<task-id>`, без абстракций «на
  будущее» и без рефакторинга вне scope задачи.
- Компонентные стили только через Emotion; единственный `.css` — `tokens.css`.
- antd-first: готовый компонент antd предпочтительнее самописного дубля;
  свои компоненты — только при отсутствии аналога, с обоснованием в отчёте.
- Данные и API не меняются, кроме `api_key?` и `POST /api/settings/llm/models`.

## Вне scope

- Замена antd/SVAR/FullCalendar/Recharts, AG Grid, мобильные нижние табы.
- Новые фичи и экраны; изменения API, кроме R2.2.
- Тёмная тема «только»; i18n; переезд на другой роутер/стейт-менеджер.
- 404-редиректы старых адресов сверх существующих.
- Переписывание архивных документов.

## Риски

1. **Чужие стили.** antd/SVAR/FullCalendar не на Emotion: единый вид достигается
   переопределением в `vendor.ts`. Полная унификация их вёрстки не гарантируется.
2. **Стекло и контраст.** Текстовые поверхности делаются плотными (≥ .9), иначе
   axe даст contrast на градиенте.
3. **Тесты с литералами.** Падение `test_web_build`/`test_viewer_acceptance` при
   смене разметки — обновление ассертов вместе с владельцем, не отключение.
4. **Вес бандла.** Emotion + motion + 3 веса шрифта ≈ +90–120 KB gzip; лечится
   LazyMotion, subsetting и кэшем SW.
5. **Порядок переименования.** R4 идёт последним, чтобы не конфликтовать по
   путям с остальными задачами; до него сборка ищется в `viewer/dist`.
6. **Шрифт.** woff2 берутся из `@fontsource/roboto-condensed` (OFL) в
   `public/fonts` без рантайм-зависимости; если пакет недоступен — владелец
   кладёт файлы, код к этому готов.
