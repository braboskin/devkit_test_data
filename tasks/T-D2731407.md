# Профиль: поля пользователя, аватар и настройки без JSON

## Brief

Профиль пользователя — основной экран аккаунта. Поля (логин, пароль, имя, фамилия, город, возраст, род деятельности) хранятся на users и правятся через PUT /api/me; агент читает их в системном промпте, отдельного JSON-контекста нет. Аватар: клик по кругу загружает фото, красный крестик удаляет (DELETE /api/profile/avatar). /profile: сетка «аватар слева / поля справа» на широком экране и в одну колонку на мобильном, «Внешний вид» включает свою картинку фона, нижняя навигация удаляется. /settings остаётся без секции «Профиль» (JSON).
