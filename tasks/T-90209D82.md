# CI на GitHub: workflow проверок и self-hosted runner

## Brief

В репозитории xaylpq/atlas нет GitHub Actions, поэтому PR не получает проверок (devkit ship в PR-режиме висит в ожидании checks). Нужно: (1) workflow `.github/workflows/ci.yml`, который на self-hosted Windows-раннере выполняет те же проверки, что devkit profile: unit-tests (список модулей из devkit.yaml) и web-build (`npm ci && npm run build` в viewer); (2) скрипт/инструкция установки self-hosted runner на этом ПК (скачивание actions-runner, config.cmd с токеном из GitHub Settings → Actions → Runners, запуск как сервис). Acceptance: на PR запускается job, зелёный при рабочем коде; ship в PR-режиме видит checks. Риски: раннер работает под Windows-аккаунтом, нужны Python/Node; токен раннера выдаёт владелец.
