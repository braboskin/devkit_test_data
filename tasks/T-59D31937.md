# Роутинг: SPA-fallback и страница 404

## Brief

Причина: StaticFiles(html=True) на / отдаёт 404 JSON на GET /settings, поэтому deep link умирает на сборке. Подкласс StaticFiles отдаёт index.html на неизвестные пути, /api/** и /health остаются JSON 404. Новый слайс pages/not-found (заголовок, путь, кнопка «На главную»), маршрут * вместо Navigate. Тесты: fallback на сборке, JSON 404 для /api/nope, e2e /nope → 404 → /. Легаси-редиректы сохраняются.
